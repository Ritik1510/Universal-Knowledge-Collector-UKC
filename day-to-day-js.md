In day-to-day JavaScript development, a core set of built-in methods is used constantly to handle arrays, manipulate text, process objects, and parse data. [1]

## Array Methods

* map(): Transforms each item in an array and returns a brand-new array.
* filter(): Removes items that do not pass a conditional test, returning a smaller array.
* reduce(): Condenses an array down to a single value (like a total sum or combined object).
* find(): Returns the very first element that matches a specific condition.
* some(): Returns true if at least one element passes a test.
* includes(): Checks if an array contains a specific value.
* push() / pop(): Adds or removes items at the end of an array. [1, 2, 3, 4] 

## String Methods

* trim(): Removes extra whitespace from both ends of a string (great for form inputs).
* split(): Breaks a string into an array of smaller pieces based on a separator.
* includes(): Checks if a text snippet exists inside a string.
* replace(): Swaps out a matched substring or pattern with new text.
* toLowerCase() / toUpperCase(): Changes case for uniform comparisons. [1, 5, 6] 

## Object & Utility Methods

* Object.keys(): Extracts an array of an object's keys.
* Object.values(): Extracts an array of an object's values.
* Object.entries(): Returns an array of key-value pairs [key, value] to loop through objects easily.
* JSON.parse() / JSON.stringify(): Converts JSON strings to usable objects and vice versa during API requests. [1, 6, 7]
